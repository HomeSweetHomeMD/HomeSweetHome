# Home Sweet Home — Mszana Dolna

Lekka, wielostronicowa strona wizytówkowa wykonana w HTML, CSS i JavaScript bez dodatkowych zależności.

## Podstrony

- `index.html` — strona główna z interaktywnym wyborem dat pobytu
- `apartament.html` — opis apartamentu i udogodnień
- `galeria.html` — zdjęcia obiektu z powiększaniem i nawigacją klawiaturą
- `okolica.html` — inspiracje na pobyt w Mszanie Dolnej i okolicy
- `kontakt.html` — dane kontaktowe, mapa i linki do rezerwacji
- `logo.svg` — nowe logo apartamentu użyte w nagłówkach i jako ikona karty

## Podgląd lokalny

Otwórz `index.html` w przeglądarce albo uruchom w katalogu projektu prosty serwer statyczny, np. `python -m http.server 8000`, a następnie przejdź pod `http://localhost:8000`.

Zdjęcia apartamentu są osadzone z galerii oferty Booking.com, a zdjęcia i informacje o mieście pochodzą z miejskich i turystycznych stron źródłowych. Rezerwacje prowadzą do Booking.com i Airbnb. Strona nie przechowuje danych rezerwacji ani nie zawiera backendu.
